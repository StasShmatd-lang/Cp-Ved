# Кризис-лототрон ведущего

SPA для ведущего и зала: крутишь приз-колесо — выпадает одна из **11** кризисных ситуаций с короткими шагами «что делать».

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm start
```

## Сценарий

1. Открой приложение на ноуте / планшете ведущего (или на экране зала).
2. Нажми **Крутить** — колесо крутится и выбрасывает карточку ЧП.
3. На карточке: формулировка ситуации + 2–4 шага действий.
4. **Ещё раз** — новый случайный кризис.
5. **Режим зала** — fullscreen для проекции.
